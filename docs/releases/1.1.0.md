# Kafi Kafi 1.1.0

This release is prepared locally and has not been published. It replaces the Kotlin/JVM application with the Rust/Tauri desktop runtime and React interface.

## Changes

- Choose a light or dark theme in Settings. The choice is saved immediately and restored on the next launch.
- Use imported producer templates from the topic's Produce section. Selecting a template fills the key, value, partition and headers without sending a record. Null values remain tombstones; empty and null keys remain distinct until edited. Creating or saving new templates in the interface is not supported yet.
- Work with consistent outline icons, compact controls, clearer topic navigation, aligned tables with highlighted selection and a record inspector.
- Confirm destructive actions with buttons that name the action, such as **Delete topic** or **Delete profile**.
- Browse messages through bounded Rust buffers and virtualized tables. Kafka operations and credential storage run in the native runtime.

## Existing installations

Profiles, settings, message templates and credentials can be imported explicitly from existing `~/.lightkafka` files through Settings. The original files are retained. JKS certificates require conversion to PEM or PKCS#12. See [credential migration](../security/credentials.md).

## Validation and publication

The [release procedure](../releasing.md) builds Windows x64 NSIS and portable ZIP packages, Linux x64 AppImage, and separate Intel and Apple Silicon macOS DMGs. Each platform's artifacts include a SHA-256 manifest.

Cross-platform installation and system-credential checks, controlled cold-start measurements and long-duration memory/throughput measurements remain incomplete. The recorded Windows idle-memory sample exceeds the project's target. These gaps are tracked in [migration acceptance](../work/TASK-MIGRATION-001.md); local release preparation does not mark them complete.

Packages are unsigned, and automatic updates and macOS notarization are not configured.
